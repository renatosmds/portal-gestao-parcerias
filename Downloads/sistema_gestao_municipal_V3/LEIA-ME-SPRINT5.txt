SGM V3 — SPRINT 5: CONSOLIDAÇÃO DE ACESSOS

BASE
Este pacote foi produzido sobre a V3 atual enviada pelo usuário.

CORREÇÕES
- Remove a rota incorreta /login/ -> apps.core.urls.
- Remove duplicidade de /accounts/.
- Mantém /login/ somente como redirecionamento compatível para /accounts/login/.
- Dashboard passa a retornar 403 controlado quando o usuário não possui
  Funcionario ou Empresa, em vez de AttributeError.
- Cabeçalho mostra perfil e empresa.
- Link para Django Admin aparece para usuários staff.
- Menu Funcionários respeita a permissão view_funcionario.
- Adiciona comando diagnosticar_acessos.
- Adiciona testes automáticos do fluxo login/logout.

APLICAÇÃO
1. Backup:
   git add .
   git commit -m "Backup antes da Sprint 5"

2. Extraia o ZIP.

3. Mescle na raiz da V3:
   apps
   gestao_rh
   templates

4. Confirme a substituição dos arquivos.
5. Preserve .env, db.sqlite3 e media.

VALIDAÇÃO
python manage.py check
python manage.py test apps.core.tests.test_authentication
python manage.py diagnosticar_acessos
python manage.py runserver

RESULTADOS ESPERADOS
- /accounts/login/ abre o login.
- /login/ redireciona ao login oficial.
- Logout funciona somente por POST.
- Usuário sem Funcionario/Empresa recebe página 403, sem erro técnico.
- Cabeçalho informa perfil e empresa quando disponíveis.

ATRIBUIÇÃO DE PERFIS
Use:
python manage.py configurar_perfis --administrador SEU_USERNAME

Ou acesse:
http://127.0.0.1:8000/admin/auth/user/

Não exige makemigrations nem migrate.
