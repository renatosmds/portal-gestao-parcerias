SGM V3 — SPRINT 9: MODERNIZAÇÃO DO MÓDULO PARCERIAS

PRINCIPAIS ENTREGAS
- Listagem moderna em cards.
- Pesquisa por termo, OSC, fornecedor e status.
- Filtro por situação e empresa.
- Cadastro, edição, detalhes e exclusão.
- Upload de documentos.
- Isolamento multitenant.
- Permissões por perfil.
- Menu Parcerias corrigido para abrir o módulo correto.
- Django Admin modernizado.
- Testes automáticos.
- Remoção de objects = None, que desativava o manager do model.
- Remoção do __init__ inadequado do model.
- Remoção da criação automática indevida de usuário.
- Referências tardias entre models para evitar importações circulares.

ALTERAÇÃO DO BANCO
Esta Sprint adiciona novamente o vínculo empresa ao model Parcerias,
que havia sido removido pela migration antiga 0004.

É obrigatório executar:
python manage.py migrate

Os registros antigos são preservados e poderão ficar inicialmente sem empresa.
O administrador deverá revisar e vincular esses registros.

COMO APLICAR
1. Faça backup:
   git add .
   git commit -m "Backup antes da Sprint 9 Parcerias"

2. Extraia o ZIP e mescle:
   apps
   templates
   static

3. Preserve:
   .env
   db.sqlite3
   media
   manage.py

4. Execute:
   python manage.py check
   python manage.py migrate
   python manage.py configurar_perfis
   python manage.py test apps.parcerias.tests.test_access
   python manage.py runserver
