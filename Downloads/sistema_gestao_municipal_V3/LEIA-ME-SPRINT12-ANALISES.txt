ALTERA O BANCO
O app Analise não possuía migrations aplicadas nem tabela no SQLite enviado.
Foi criada a migration inicial:
apps/analise/migrations/0001_initial.py

APLICAÇÃO
1. Faça backup.
2. Mescle apps, templates e static.
3. Preserve .env, db.sqlite3, media e manage.py.
4. Execute um comando por vez:
   python manage.py check
   python manage.py migrate
   python manage.py configurar_perfis
   python manage.py test apps.analise.tests.test_access
   python manage.py runserver

ACESSO
http://127.0.0.1:8000/analise/

Não execute makemigrations. A migration inicial já está incluída.
