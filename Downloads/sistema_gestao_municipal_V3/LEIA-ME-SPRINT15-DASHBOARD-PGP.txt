SPRINT 15 — DASHBOARD INTEGRADO
PORTAL DE GESTÃO DE PARCERIAS (PGP)
============================================================

OBJETIVO
Criar a primeira visão integrada da plataforma para o Órgão Público e para as
Organizações da Sociedade Civil, utilizando os módulos já existentes.

PRINCIPAIS ENTREGAS
- Nova identidade: Portal de Gestão de Parcerias (PGP).
- Dashboard separado em Área do Órgão Público e Área da OSC.
- Alternância de visão disponível para superusuários.
- Filtros por OSC, Termo e período.
- Indicadores de Termos, Prestações, Lançamentos, Documentos e Análises.
- Consolidação dos valores lançados, analisados, aprovados e glosados.
- Painel de prioridades e pendências.
- Indicadores de conformidade documental e avanço das análises.
- Distribuições por situação, atividade mensal e registros recentes.
- Quadro de acompanhamento por Termo.
- Dashboard vazio e orientativo para usuário ainda sem OSC vinculada,
  substituindo o antigo erro 403.
- Tela de login e estrutura principal renomeadas para PGP.
- Versão dos arquivos CSS adicionada às URLs para reduzir problemas de cache.
- Comando opcional para criação dos perfis iniciais do PGP.

ARQUIVOS PRINCIPAIS
- apps/core/dashboard.py

INSTALAÇÃO
1. Faça uma cópia de segurança da pasta atual.
2. Extraia o ZIP da Sprint 15.
3. Copie/mescle a pasta sistema_gestao_municipal_V3 sobre o projeto atual.
4. Preserve o seu arquivo .env, o banco db.sqlite3 e a pasta media.
5. Ative o ambiente virtual do projeto.
6. Execute:

   python manage.py check
   python manage.py migrate
   python manage.py collectstatic --noinput

7. Opcionalmente, configure os novos grupos de acesso:

   python manage.py configurar_perfis_pgp

8. Inicie o servidor:

   python manage.py runserver

9. No navegador, faça uma atualização completa com Ctrl+F5.

COMO O SISTEMA DEFINE A ÁREA
- Superusuário e usuário staff: Área do Órgão Público.
- Usuário não staff: Área da OSC.
- Grupos cujo nome contenha OSC, Representante, Contador, Consultor ou
  Gestor Financeiro: Área da OSC.
- O superusuário pode alternar entre as duas visões para conferência.

SEGURANÇA DO ESCOPO
Os usuários comuns continuam vendo somente os registros da empresa vinculada
ao seu cadastro de funcionário. O superusuário pode consultar todas as OSCs ou
filtrar uma entidade específica.

IMPORTANTE SOBRE O PERÍODO
O filtro de período utiliza:
- assinatura para os Termos;
- data do documento para Lançamentos e Documentos;
- data de criação para Análises.
A Prestação atual ainda não possui data padronizada própria e, por isso, é
filtrada pelo Termo, não pelo período. Esse modelo será aperfeiçoado nas
próximas sprints.

BANCO DE DADOS
Esta sprint não cria modelos nem exige novas migrações próprias. O comando
migrate é recomendado apenas para garantir que as migrações existentes estejam
aplicadas.

TESTES
O projeto recebeu testes para:
- acesso do superusuário sem funcionário vinculado;
- indicadores consolidados do dashboard;
- identificação de usuário da OSC;
- tratamento de usuário sem empresa vinculada.

Execute:

   python manage.py test apps.core
