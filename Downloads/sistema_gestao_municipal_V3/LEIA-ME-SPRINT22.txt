SPRINT 22 — IMPORTAÇÕES E PORTÁTIL REAL

Instalação:
1. Copie os arquivos sobre o projeto principal.
2. python -m pip install -r requirements-dev.txt
3. python manage.py check
4. python manage.py migrate
5. python manage.py test apps.importacoes
6. python manage.py runserver

Central: http://127.0.0.1:8000/importacoes/

Colunas básicas:
OSCs: nome (ou razao_social/osc)
Termos: numtermo, nomeosc, tipo, objeto, inicio_vigencia, termino_vigencia, valor_global, valor_repasse, status, processo_sei
Prestações: numtermo, tipo_termo, credor, cpf_cnpj, valor_contrato, situacao
Lançamentos: empresa, numero_lancamento, numtermo, tipo_documento, numero_documento, data_documento, data_pagamento, descricao, valor

PORTÁTIL REAL:
Execute portable_real\construir_portatil.bat no computador principal. Depois copie apenas dist\Portal_Gestao_Parcerias_Portatil para o pendrive. No destino, execute iniciar_portal.bat. Não há pip/venv no pendrive.
