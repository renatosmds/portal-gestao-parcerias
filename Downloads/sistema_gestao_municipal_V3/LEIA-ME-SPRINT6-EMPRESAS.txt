SGM V3 — SPRINT 6: MODERNIZAÇÃO DO MÓDULO EMPRESAS

ENTREGA
- Nova listagem em cards, com pesquisa e paginação.
- Página de detalhes da empresa.
- Cadastro e edição modernos.
- Exclusão com confirmação.
- Mensagens de sucesso.
- Validação de nome duplicado.
- Permissões reais por perfil.
- Escopo por empresa:
  superusuário vê todas;
  demais usuários veem somente a própria empresa.
- Menu Empresas no layout principal.
- Django Admin melhorado.
- Testes básicos do módulo.
- Comando configurar_perfis atualizado.

PERFIS
Administrador:
- visualizar, cadastrar, editar e excluir empresas.

Gestor:
- visualizar e editar a própria empresa.

Analista:
- visualizar a própria empresa.

Usuário:
- visualizar a própria empresa.

ANTES DE APLICAR
git add .
git commit -m "Backup antes da Sprint 6 Empresas"

COMO APLICAR
1. Extraia o ZIP.
2. Mescle na raiz da V3:
   apps
   templates
   static
3. Confirme a substituição dos arquivos.
4. Preserve:
   .env
   db.sqlite3
   media
   manage.py

COMANDOS
python manage.py check
python manage.py configurar_perfis
python manage.py test apps.empresas.tests.test_access
python manage.py runserver

ACESSOS
http://127.0.0.1:8000/empresa/
http://127.0.0.1:8000/empresa/novo/

IMPORTANTE
- Não altera o model Empresa.
- Não exige makemigrations.
- Não exige migrate.
- Se o usuário comum não possuir Funcionario/Empresa vinculado, a lista fica vazia.
